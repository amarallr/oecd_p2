# Segurança

O projeto disponibiliza uma página didática e ferramentas de preparação. Não é um serviço para dados reais nem um motor apto a cumprir obrigações tributárias. O navegador não transmite os valores do demonstrador a servidor algum.

Não envie dados reais, segredos ou detalhes exploráveis de vulnerabilidades em issues públicas. O reporte privado de vulnerabilidades ainda precisa ser habilitado e verificado pelo proprietário; não anunciamos endereço ou canal reservado inexistente. Até sua configuração, issues devem conter somente observações não sensíveis. A ausência de canal está registrada como pendência de liberação operacional, sem impedir leitura e uso dos exemplos públicos.

Uma correção deve identificar versões afetadas, impacto, mitigação e evidências de teste, preservando dados privados. Dependências e actions de CI são revisadas e fixadas por versão ou commit. Nunca instalar código arbitrário de pacote nacional não revisado.
